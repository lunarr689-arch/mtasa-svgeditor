# MTA:SA SVG Editor

[![portfolio](https://img.shields.io/badge/my_portfolio-000?style=for-the-badge&logo=ko-fi&logoColor=white)](https://boversoneg.github.io/)

Complete SVG Generator and Editor made within MTA:SA. Goal is to achieve an actual fully-functional UI Designing program such as Figma.

This project is being made to show capabilities of MTA:SA and SVG within. Current version of luna-svg implemented into MTA:SA is not capable of some functionalities but I'll try to keep project up-to-date.




## Roadmap

- [ ] Full viewbox (Pan, Zoom, Customize)
- [ ] Shapes editor
    - [ ] Rectangles
    - [ ] Lines
    - [ ] Ellipses
    - [ ] Polygons
- [ ] Texts
- [ ] Color picker (RGB, HSV, Hex, HSL, HSB, CSS)
- [ ] Gradients
- [ ] Pen (Custom shapes)
- [ ] Auto layout
- [ ] Fonts importing
- [ ] Hierarchy tree
